# URL Shortener Desktop

**Прежнее название репозитория:** `3Sem3Practice`.

Сервис сокращения ссылок на C++: HTTP API, сервер хранения данных, CLI и настольный клиент для macOS с праздничным интерфейсом.

**Примерный период реализации:** декабрь 2025. Период указан по истории Git и отражает основную работу над проектом.

## Описание

URL Shortener - это высокопроизводительный сервис для создания коротких ссылок, написанный на C++17. Система состоит из нескольких компонентов: сервера базы данных, HTTP сервера для обработки запросов сокращения и клиентских приложений (CLI и GUI) с новогодней тематикой.

## Особенности

- **Многокомпонентная архитектура**: Отдельные серверы для БД и HTTP API
- **Многопоточность**: Обработка множественных клиентских подключений
- **Потокобезопасность**: Все операции с базой данных защищены мьютексами
- **Автосохранение**: Автоматическое сохранение данных в JSON формате
- **Новогодний GUI**: Графический интерфейс с елочкой, снежинками и гирляндами
- **Детерминированные коды**: Одинаковые URL получают одинаковые короткие коды
- **HTTP API**: RESTful интерфейс для интеграции с другими приложениями

## Компоненты системы

### 1. Сервер базы данных (`program`)
Многопоточный TCP сервер для хранения данных с поддержкой различных структур данных:
- Множества (Sets)
- Стеки (Stacks) 
- Очереди (Queues)
- Хеш-таблицы (Hash Tables)
- Бинарные деревья (Binary Trees)

### 2. HTTP сервер (`url_server`)
HTTP API сервер для обработки запросов сокращения URL:
- `POST /` - сокращение URL
- `GET /{code}` - перенаправление по короткому коду

### 3. CLI клиент (`url_shortener`)
Консольное приложение для быстрого сокращения URL из командной строки.

### 4. GUI приложение (`url_shortener_gui`)
Графическое приложение для macOS с новогодним дизайном:
- Елочка в центре интерфейса
- Снежинки и гирлянды
- Интуитивный интерфейс для сокращения ссылок

## Установка и сборка

### Требования
- C++17 совместимый компилятор (clang++ или g++)
- Make
- macOS (для GUI приложения)
- nlohmann/json библиотека (включена в проект)

### Сборка всех компонентов
```bash
# Сборка всех компонентов
make both

# Сборка с GUI приложением
make all-gui

# Сборка отдельных компонентов
make program          # Сервер БД
make url_server       # HTTP сервер
make url_shortener    # CLI клиент
make url_shortener_gui # GUI приложение
```

### Отладочная сборка
```bash
make dev              # CLI клиент с отладкой
make dev-db           # Сервер БД с отладкой
make dev-server       # HTTP сервер с отладкой
```

### Оптимизированная сборка
```bash
make release          # Оптимизированный CLI
make release-db       # Оптимизированный сервер БД
```

## Использование

### Запуск системы

1. **Запуск сервера базы данных:**
```bash
./program --server --file data/db.json --port 6379
```

2. **Запуск HTTP сервера:**
```bash
./url_server
```

3. **Использование CLI клиента:**
```bash
./url_shortener https://github.com/
./url_shortener "https://example.com?param=value"
```

4. **Запуск GUI приложения:**
```bash
./url_shortener_gui
# или
make run-gui
```

### Быстрый запуск GUI
```bash
# Используйте готовый скрипт
./start_gui.sh
```

### HTTP API

#### Сокращение URL
```bash
curl -X POST http://localhost:8080/ \
  -H "Content-Type: application/json" \
  -d '{"url": "https://github.com/"}'
```

Ответ:
```json
{
  "short_code": "abc123",
  "original_url": "https://github.com/",
  "shortened_url": "http://localhost:8080/abc123"
}
```

#### Перенаправление
```bash
curl -L http://localhost:8080/abc123
# Перенаправляет на https://github.com/
```

## Алгоритм сокращения

1. **Валидация URL** - проверка корректности формата
2. **Поиск существующего кода** - проверка, не сокращался ли URL ранее
3. **Генерация детерминированного кода** - создание кода на основе хеша URL
4. **Проверка уникальности** - убеждение в отсутствии коллизий
5. **Сохранение в БД** - запись сопоставления код-URL

## Формат данных

База данных сохраняется в JSON формате:
```json
{
    "hashes": {
        "urls": {
            "abc123": "https://github.com/",
            "def456": "https://google.com/"
        }
    }
}
```

## Безопасность и производительность

- **Потокобезопасность**: Все операции с БД защищены мьютексами
- **Детерминированность**: Одинаковые URL всегда получают одинаковые коды
- **Автосохранение**: Данные сохраняются после каждой операции
- **Обработка ошибок**: Корректная обработка сетевых и системных ошибок
- **Graceful shutdown**: Корректное завершение по сигналам
